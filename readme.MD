# Site Template Construction

This project is a reusable website template for construction and home-service businesses. It is designed to be easily adapted for other companies that want a polished, high-performance online presence without starting from scratch.

## What this template includes

- A modern, responsive static site built with Eleventy (11ty)
- Tailwind CSS v4 for fast styling and customization
- Docker-based local development and production deployment
- Caddy as the web server for efficient static asset delivery
- Content-driven pages for services, gallery, contact, and thank-you flow

## Best for

This template is a strong starting point for contractors, roofers, remodelers, landscapers, painters, and other local service businesses that want a professional website with clear calls to action.

## Getting started

Use this project as a foundation, then customize the content, branding, images, and service details to fit a new business.

## Tech stack

- Eleventy
- Tailwind CSS
- Docker
- Caddy
